# AI Demo Prompts

Use these examples to validate the gallery assistant and local AI flows:

- Find peaceful mountain photographs
- Show blue artworks
- Describe this artwork
- Which artworks contain landscapes?
- Find similar artwork
- Why did you recommend these artworks?

## Sample AI flow

```text
User query
  ↓
Embedding + local vector search
  ↓
Relevant artwork context
  ↓
RAG prompt
  ↓
AI response + matching cards
```
